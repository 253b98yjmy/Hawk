# Hawk 設計書

Hawk は C 言語で一から書く、軽量・プライバシー重視の Web ブラウザです。
JavaScript を実装しないことを前提に、Chromium / Gecko / WebKit には一切依存しません。

## 目標

1. **最小のメモリと CPU 使用量**で、文章中心の Web サイトを快適に読めること。
2. **プライバシー最優先**：追跡されにくい初期設定、テレメトリなし、ブロッカーを標準搭載。
3. **自作エンジン**：HTML/CSS の解析・レイアウト・描画はすべて自前で実装する。

### 対象サイト（受け入れ基準に使う）

- Wikipedia（日本語版・英語版）
- MDN、各種技術ドキュメント、GitHub のコード閲覧ページ（JS なしで閲覧可能な範囲）
- ニュースサイト、個人ブログ、Hacker News、DuckDuckGo の HTML 版
- 検索フォームなど、JavaScript なしで動く HTML フォーム

## 非目標（実装しない）

- JavaScript、WebAssembly、およびそれに依存する全 Web API（DOM API、fetch、Storage、Service Worker など）
- WebGL、Canvas、WebRTC、動画・音声の再生（`<video>` / `<audio>` は外部プレイヤーで開くリンクとして表示）
- 拡張機能 API
- マルチプロセスでのサイト分離（代わりに OS の緩和策と、攻撃面の縮小で守る。01 章参照）
- CSS アニメーション・トランジション（最終状態だけを描画する）
- 印刷、アクセシビリティ API（初期は対象外。将来課題）

## 主要な決定事項

| 領域 | 決定 | 理由 |
|---|---|---|
| 対象 OS | Windows 11 x64（ARM64 は後日） | Windows 10 はサポート終了済み。SChannel の TLS 1.3 が使える |
| 言語・規格 | C17、MSVC と clang-cl の両方でビルド可能に保つ | ASan と libFuzzer は clang-cl で使う |
| ビルド | CMake + Ninja | 標準的で、IDE 連携も容易 |
| プロセス | シングルプロセス | メモリ最小。JS がないため攻撃面が小さい |
| スレッド | メイン（UI・エンジン）＋ I/O の 2 本 | ロックを最小化しつつ、通信や画像展開で UI を止めない |
| 文字列 | 内部は UTF-8。DirectWrite に渡す直前だけ UTF-16 | メモリ効率と移植性 |
| DOM | パース完了後は不変（JS がないため） | アリーナ確保・スタイル共有・事前索引が使え、大幅に軽くできる |
| TLS | SChannel（OS 標準） | 追加バイナリなし。証明書ストアと更新を OS に任せられる |
| テキスト | DirectWrite（字形整形、フォールバック、改行位置、グリフのラスタライズ） | OS 標準で、日本語の品質が高い |
| 描画 | CPU による自前ラスタライザ → GDI で転送 | GPU デバイスのメモリ消費を避ける。移植しやすい |
| 画像 | WIC（OS 標準）で、表示サイズに縮小しながら展開 | 追加ライブラリ不要。展開後のメモリを最小化できる |
| 圧縮 | zlib（gzip/deflate）。Brotli は後日 | ファジング実績が豊富 |
| HTTP | HTTP/1.1 を自前実装。HTTP/2 は M6 以降に検討 | 実装量と効果の釣り合い |
| iframe | 描画しない。「埋め込み: ホスト名」というリンクで代替 | 軽量化とプライバシーの両方に効く |
| Web フォント | 既定は無効（設定で有効化） | 通信・メモリ・追跡の削減 |
| ブロッカー | エンジンに組み込み。ネットワーク層と CSS カスケードで直接処理 | 拡張機能 API より速く、軽い |
| 設定画面 | `hawk:` スキームの内部ページを、自前エンジンで HTML フォームとして描画 | JS なしでも UI を作れ、専用の UI コードが不要 |

## 方針に関する決定（2026-11-18 確定）

| # | 論点 | 決定 | 反映先 |
|---|---|---|---|
| D1 | Hawk 自体のライセンス | **GPLv3**。同梱するフィルタリストは、GPLv3 と両立するライセンスのものに限る。それ以外のリストは、初回起動時にユーザーの確認を得てからダウンロードする | 04 章 6 節 |
| D2 | User-Agent 文字列 | **Windows 版 Firefox ESR と同じ文字列**。最新の ESR に合わせて、ブラウザの更新ごとに見直す | 02 章 5 節 |
| D3 | 既定で有効にするフィルタリスト | EasyList、EasyPrivacy、uBlock filters（本体・privacy・unbreak）、AdGuard Japanese filter、Peter Lowe's list。**配布を始める前に**、各リストのライセンスと、同梱するかダウンロードにするかを確認する | 04 章 6 節 |
| D4 | Cookie の既定 | ファーストパーティの永続 Cookie は保存し、サードパーティの Cookie は完全に拒否する | 02 章 7 節 |
| D5 | 履歴の既定 | 90 日間保存する。設定で「保存しない」を選べる | 05 章 5 節 |
