# 05. UI シェルと永続化

## 1. ウィンドウ構成

```
┌──────────────────────────────────────────────┐
│ [タブ1][タブ2][＋]                      _ □ × │ ← タブ列（自前描画。タイトルバーと一体化）
├──────────────────────────────────────────────┤
│ ← → ⟳  [ https://example.com/        ] 🛡12 ☰ │ ← ツールバー
├──────────────────────────────────────────────┤
│                                              │
│              コンテンツ領域（エンジン）           │
│                                              │
├──────────────────────────────────────────────┤
│ 読み込み中: example.com …                      │ ← 状態表示（必要なときだけ）
└──────────────────────────────────────────────┘
```

- **ウィンドウ**：トップレベルは Win32 のウィンドウ 1 つ。
  - タブ列は、`DwmExtendFrameIntoClientArea` と `WM_NCCALCSIZE` でタイトルバー領域に描く。
  - コンテンツ領域は子ウィンドウにする（エンジンの描画先）。
- **アドレスバー**：OS 標準の `EDIT` コントロールを使う。IME・クリップボード・取り消しを OS から無料で得られるため。
  - サブクラス化して、Enter での移動、Esc での復元、補完候補（履歴とブックマーク）のドロップダウンを追加する。
  - 入力が URL でない場合は検索として扱う。既定の検索エンジンは DuckDuckGo の HTML 版（`html.duckduckgo.com`）。設定で変更できる。
- **🛡 の数字**：現在のタブで遮断した件数。クリックすると、そのサイトでのブロッカーの有効・無効を切り替えるメニューと、`hawk:blocker` へのリンクを表示する。
- **☰ メニュー**：新しいタブ、新しいウィンドウ、履歴、ブックマーク、ダウンロード、ページ内検索、拡大縮小、設定、終了。
- **ダークモード**：`DWMWA_USE_IMMERSIVE_DARK_MODE` で、システム設定に連動させる。ページ側には `prefers-color-scheme` で伝える。
- **拡大縮小**：Ctrl+ホイール、Ctrl+±、Ctrl+0。サイトごとに倍率を記憶する。

### 1.1 M3 での実装

- **タブ列とツールバー**は、M3 ではクライアント領域の上端（72 CSS px）に自前で描く（`src/ui/hk_chrome.c`）。タイトルバーとの一体化（`DwmExtendFrameIntoClientArea`）は M4 で行う。
  - 描画はページと同じ描画リストとラスタライザを使う。アイコンは Segoe Fluent Icons（なければ Segoe MDL2 Assets、どちらもなければ Unicode の記号）。
  - コンテンツ領域は子ウィンドウにせず、同じバックバッファの下側に描く。
- **アドレスバー**：`EDIT` コントロールをサブクラス化した。Enter で移動、Esc と Tab で元の URL に戻してページにフォーカスを返す。最初のクリックで全体を選択し、Ctrl+Backspace で 1 語を消す。補完候補はまだない。
  - 入力が `scheme://` を含むか、空白がなく `.` か `:` を含む場合は URL（スキームがなければ `https://` を補う）。それ以外は DuckDuckGo の HTML 版で検索する。
- **タブ**：タブごとにページ（DOM、スタイル、描画リスト、画像）と履歴を持つ。背景のタブも破棄しない（段階的な破棄は M4）。
  - Ctrl+クリックと中クリックは背景のタブで開き、`target=_blank` は前面の新しいタブで開く。タブの中クリックで閉じる。最後のタブを閉じるとウィンドウを閉じる。
- **`hawk:` へのリンク**：内部ページからだけ辿れる（3 節の偽装の防止）。
- **`opacity: 0`**：フォーム部品の表示に伴い、`opacity: 0` で隠した部品（Wikipedia のメニューなど）が見えてしまうため、`visibility: hidden` と同じ扱いで隠すようにした。

## 2. キーボードショートカット

| キー | 動作 |
|---|---|
| Ctrl+T / Ctrl+W / Ctrl+Shift+T | 新しいタブ / タブを閉じる / 閉じたタブを開き直す |
| Ctrl+Tab / Ctrl+Shift+Tab / Ctrl+1〜9 | タブの切り替え |
| Ctrl+L / Alt+D / F6 | アドレスバーにフォーカス |
| Alt+← / Alt+→ / Backspace | 戻る / 進む / 戻る（設定で有効にした場合） |
| F5 / Ctrl+R / Ctrl+F5 | 再読み込み / キャッシュを無視して再読み込み |
| Ctrl+F / F3 / Shift+F3 | ページ内検索 / 次を検索 / 前を検索 |
| Ctrl+D / Ctrl+H / Ctrl+J | ブックマークに追加 / 履歴 / ダウンロード |
| Space / Shift+Space / Home / End / 矢印キー | スクロール |
| Tab / Shift+Tab | リンクとフォーム部品の間でフォーカスを移動 |
| Ctrl+U | ソースを表示（`hawk:source?url=...`） |

## 3. 内部ページ（`hawk:` スキーム）

設定などの画面は、**自前エンジンで描画する HTML フォーム**として実装する。JS がなくても UI を作れ、専用の UI コードが不要になる。

| ページ | 内容 |
|---|---|
| `hawk:newtab` | 新しいタブ。検索欄とブックマークの一覧 |
| `hawk:settings` | 設定 |
| `hawk:blocker` | ブロッカー（04 章 7 節） |
| `hawk:history` / `hawk:bookmarks` / `hawk:downloads` | 履歴 / ブックマーク / ダウンロード |
| `hawk:source?url=` | ソースの表示 |
| `hawk:about` | バージョン、ライセンス、メモリ使用量の内訳（モジュールごとのアリーナ使用量など） |
| `hawk:error?...` | 通信エラー、証明書エラー、遮断ページ |

- **フォームの送信先**：`hawk:` のハンドラ（C の関数）が POST を受け取り、設定を変更してから、リダイレクトで同じページを表示し直す。
- **偽装の防止**：外部のページから `hawk:` の URL へは移動できず、フォームも送信できない。トップレベルのナビゲーションで、ユーザーが直接入力した場合と、内部ページ間の移動に限る。
- **CSRF 対策**：内部ページのフォームには、起動ごとに生成するトークンを埋め込む。

## 4. ダウンロード

- 名前を付けて保存するダイアログ（`IFileSaveDialog`）。既定の保存先は「ダウンロード」フォルダ。
- I/O スレッドで、ディスクへ直接書き込む（メモリにため込まない）。
- `hawk:downloads` で進捗の確認、キャンセル、フォルダを開く操作ができる。
- ダウンロードしたファイルにはゾーン識別子（Mark of the Web）を付ける。`IAttachmentExecute` を使い、Windows の標準的な保護に任せる。

## 5. データの保存

保存先は `%LOCALAPPDATA%\Hawk\`（ポータブル版では、実行ファイルと同じ場所の `profile\`）。

| ファイル | 形式 | 内容 |
|---|---|---|
| `settings.ini` | INI 形式 | 設定値 |
| `history.tsv` | 追記型の TSV（時刻、URL、タイトル） | 既定の保存期間は 90 日（README の D5）。起動時に、期間を過ぎた行を取り除いて書き直す |
| `bookmarks.tsv` | TSV（フォルダのパス、タイトル、URL） | |
| `cookies.tsv` | TSV | 02 章 7 節 |
| `session.tsv` | TSV | 開いていたタブ（URL とスクロール位置）。クラッシュから復元するために 30 秒ごとに保存 |
| `site_prefs.tsv` | TSV | サイトごとの設定：ブロッカーの無効化、拡大縮小の倍率、HTTP の許可、Cookie の許可・拒否 |
| `filters\`、`cache\` | 04 章 / 02 章 | |

- SQLite は使わない。データ量が小さく、単純な形式で十分なため。
- 書き込みはすべて「一時ファイルに書く → `FlushFileBuffers` → `ReplaceFileW` で差し替え」の手順で行い、途中で落ちても壊れないようにする。
- 「終了時に消去」の設定：履歴、Cookie、キャッシュ、セッションを個別に選べる。
- **プライベートウィンドウ**：何もディスクに書かない。メモリ上だけで Cookie とキャッシュを持つ。

## 6. 起動と終了

- **起動の順序**：
  1. プロセスの緩和策を設定する
  2. 設定を読み込む
  3. ウィンドウを表示する（この時点で操作可能にする）
  4. I/O スレッドを起動し、filters.bin をマップし、セッションを復元する（背景タブは休止状態のまま開く）
- **目標**：起動してからウィンドウが操作可能になるまで 100 ms 以内。
- **単一インスタンス**：2 つ目の起動は、名前付きミューテックスで検出する。URL を `WM_COPYDATA` で既存のプロセスに渡し、自分は終了する。
- **既定のブラウザへの登録**：Windows の「既定のアプリ」設定で、ユーザーが選ぶ方式にする（必要なレジストリ項目はインストーラで登録する）。
